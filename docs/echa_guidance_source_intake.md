# Phase 2 — ECHA SDS guidance source intake

**Status: Supporting evidence only; no legally verified SDS rules imported.**

## What the uploaded ZIP contains

The supplied archive \`CLP_A_I-main.zip\` (despite its name) is **not CLP Annex I or CLP Annex IV**.
It contains a 16-section Markdown extraction from the ECHA *Guidance on the compilation
of safety data sheets*, v4.0, December 2020, reference ECHA-20-H-25-EN, DOI
10.2823/77155. A nested \`ECHA_SDS_Guidance_LLM_Markdown_Only (1).zip\` contains
the same section files plus an extraction audit, source manifest and a detailed
review index. The outer 16 section files and nested copies are byte-identical.

The lightweight package explicitly excludes the **original ECHA PDF and page images**
and cannot establish the fidelity of layout-sensitive tables, footnotes or equations.
Its original-PDF SHA-256 is **asserted in metadata but cannot be verified from the
uploaded ZIP alone**.

This is guidance explaining SDS content, especially REACH Annex II. It is
**not the binding legal text**; historical guidance excerpts and
\`Text Annex II\` labels do not automatically describe obligations effective
on a modern SDS revision date.

## Source classification

| Source | Type | Role in engine |

| CLP Annex IV Parts 1 and 2 | EU legislative text | Primary source for P-statement selection criteria and legally prescribed English wording, **not included in the uploaded ZIP** |

No legally required phrase selections are created or marked verified by this intake.

## Import the uploaded archive locally

Save the original uploaded ZIP to your Downloads directory. Run from the local repository:

\`\`\`bash
cd /mnt/holochain/Regulatory/SDS_Phrases
python3 src/guidance_sources.py ~/Downloads/CLP_A_I-main.zip
python3 src/server.py
\`\`\`

This creates \`data/echa_guidance_2020.sqlite\`, ignored by Git. The importer
enforces exactly 16 matching sections, consistent ECHA document metadata,
declared SHA-256 consistency and stable source page labels. Source Markdown
is stored locally **without paraphrasing or reclassification**. Original
section texts, pages and headings remain retrievable.

The importer deliberately ignores the nested duplicate lightweight ZIP
to avoid multiplying the same source material.

New local endpoints (source lookup only):

- \`GET /api/guidance/summary\` — declared source provenance and 16 section records.
- \`GET /api/guidance/search?query=...&section=4&limit=20&offset=0\` — source
  headings, page numbers and limited previews, always marked as historical guidance.
- \`GET /guidance.html\` — source reference browser.

No legal rules are generated by these endpoints.
