# Local dependencies

Core: Python 3.10+ (standard library including sqlite3, HTTP, JSON, ZIP and XML); use Python 3.12/3.14 in CI. Core operation does not require cloud/API access or a licensed phrase catalogue. Catalogue-backed recommendations need an authorised local catalogue. Node.js 22+ is required for the Section 9 JS engine and JS tests, not for unrelated assessment checks.

Optional: `python -m pip install -r requirements-documents.txt` for PDF intake (PyMuPDF), PDF export (ReportLab), DOCX export (python-docx). DOCX intake uses standard-library ZIP/XML. TXT and JSON do not require these extras. Direct pins reflect the local QA environment; generate a platform-specific transitive lock with pip freeze after installation. Install Tesseract with English language data for scanned PDFs; Linux: `sudo apt install tesseract-ocr tesseract-ocr-eng`. Install Poppler utilities for source indexing and role builds (Linux: `sudo apt install poppler-utils`); Windows: install the tools separately and add their executable directories to PATH. Git and the pinned SDS_Author history are required for role generation. Python dependencies alone do not install these executables.

Run `python scripts/run_tests_checked.py --manifest /path/outside/repo/python-validation.json` and `node --test modules/section9/tests/rules.test.mjs`. Provision `SDS_SOURCE_DIR` with original PDFs to enable the existing package test. Follow gemini/roles/README.md for role generator. No network is needed after dependencies and input sources have been provisioned; confirm this using actual OS-level isolation, not just mock sockets. Windows isolation requires separate verification.

For original Node TAP execution evidence use `python scripts/run_js_tests_checked.py --manifest /path/outside/repo/js-validation.json`. Set `SDS_AUTHOR_DIR` to a local Git checkout containing both pinned SDS_Author revisions, alongside `SDS_SOURCE_DIR`, to enable the optional dual-role build test. Neither variable is provisioned by default in CI. The original package checker is preserved byte-for-byte and invoked with Python UTF-8 mode.
